# ai-drugs.io.vn

The website of the **Unit of Computation and AI Application Research**, Faculty of Pharmaceutical
Chemistry and Technology, Hanoi University of Pharmacy.

A static site built with [Quarto](https://quarto.org) and published to GitHub Pages by
`.github/workflows/publish.yml` on every push to `main`.

## Editing it

**A person** is a few lines in `members.yml`. `team:` decides which section they appear in —
`Principal investigator`, `AI team`, `MD team`, `Synthesis team` or `Alumni`. A photo is optional: put
a web-sized image in `assets/img/team/` and name it in `photo:`, or omit it and the card falls back to
a coloured initials circle. `role` and `initials` are optional too.

**A paper** is a DOI, one per line in `publications.txt`, with a `role=` and `scope=` annotation that
drive the ordering. Then:

```bash
export CITATION_RESOLVER_URL=http://<host>:<port>
python3 scripts/update-bib.py
```

That resolves every identifier, refuses anything it cannot confirm as published, and rewrites
`references.bib` and `publications.yml`. **Citations are never written by hand** — if the resolver
cannot confirm an entry, it does not go on the site, and the refusal is recorded in
`scripts/rejected.json`.

**Page text** is Markdown in `index.qmd`, `research.qmd`, `team.qmd`, `software.qmd`.

## Building it locally

```bash
quarto preview     # live reload on http://localhost:4321
quarto render      # build once into _site/
```

## Things worth knowing before changing them

- `_quarto.yml` has a `render:` **whitelist**. Quarto's default is to render every markdown file in
  the project; the whitelist is what stops working notes being published. Add pages one at a time and
  never replace it with a glob.
- Templates in `assets/*.ejs` have their output passed through Markdown. Any line indented four
  spaces becomes a code block, so keep every emitted line flush left.
- The home page structure viewer checks for WebGL before downloading anything, and never removes the
  poster image until the interactive view has actually rendered. The poster is the fallback for
  browsers without WebGL, so it is not decoration.
- `assets/structure/4LXZ-trimmed.pdb` is generated by `scripts/fetch-structure.py`. Regenerate it
  rather than editing it.
- All motion is behind `prefers-reduced-motion`.
